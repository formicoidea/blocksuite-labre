In a menu's search field, Enter with nothing highlighted now takes the one item the filter left, or, when it left none, the item marked `enter-default` ("Create source “typed”" in the lists of sources); several left, Enter does nothing. A menu whose search field shows from the start is at least 288px wide, so a placeholder such as « Rechercher ou créer une source » is not cut.
