New entry `@labre/affine/canvas-viewer` (ADR 0050, ADR 0051): `mountCanvasViewer(host, state, options)` shows a stored canvas, read-only, on a host's public page. It is the edgeless editor itself on a read-only store, built from the view registry plus the host's own providers (`viewExtensions`: each framework bundle's view extensions, which the published core leaves to the bundles) minus the tooling listed in `READ_ONLY_EXCLUDED_VIEW_EXTENSIONS` and `READ_ONLY_EXCLUDED_EXTENSIONS` (exported from `@labre/affine/extensions/view` with `getReadOnlyViewProviders`); a guard spec proves no excluded entry paints content. The editor pans and zooms as it does for a read-only document. A page link goes to `onOpenDoc(docId)`, an external one to `onLinkClick(url)` after `isSafeLinkUrl`; `getBlob` feeds images; `docTitles` names the other pages. `focus: { kind: 'frame' | 'group', id }` shows one element the way a surface reference shows it in a page, frozen by default (`interactive`) with `onExpand` on a click or Enter. It returns `{ zoomIn, zoomOut, fit, dispose }` and imports the whole view graph (3.65 MB gzipped): load it with a dynamic `import()`.

It holds under a strict Content-Security-Policy (no `'unsafe-inline'` style, no `'wasm-unsafe-eval'`): new `adoptShadowlessStyles()` (`@labre/std`) moves light-DOM styles to adopted style sheets, new `adoptEmotionStyles()` (`@labre/affine-shared/styles`, the library's one emotion instance, which the table and database blocks now import) does the same for emotion, new `CodeBlockConfig.engine: 'oniguruma' | 'javascript'` (default `oniguruma`) highlights code without WebAssembly, and the paragraph block's in-template `<style>` moved to its static styles. The editor keeps `<style>` elements unless a host calls the two functions, which importing `@labre/affine/canvas-viewer` does for the whole page: load the viewer on a page without the editor.

A frozen frame shows its title badge above it, as the editor draws it: its `aspect-ratio` includes the badge's strip. `CommunityCanvasTextFonts` is also exported from `@labre/affine/canvas-viewer`; the viewer loads no face itself and paints the canvas again whenever the page's own faces finish loading (`document.fonts` `loadingdone`). A frozen view's button is named `com.labre.canvas-viewer.open-titled` ("Open canvas: {{title}}"), or `com.labre.canvas-viewer.open` ("Open canvas") for an element with no title. The two-finger pinch of the edgeless editor, which the viewer runs, ignores a step whose fingers started on the same point instead of zooming to infinity. Under `default-src 'none'; script-src 'self'; style-src 'self'; font-src 'self'` the viewer still raises one `style-src-attr` report per icon (the `style` string `@blocksuite/icons` binds, whose declarations the viewer's sheet carries) and one `img-src` report (a `data:` drag image preloaded at import), neither visible (`docs/integrate/09-static-html.md`).
