Wardley maps can be read and written in the JSON language of `@formicoidea/wardley-map-renderer` (ADR 0012, amendment of 2026-10-28), beside OWM. `@formicoidea/labre-framework-wardley/interchange` and the package index export `WARDLEY_JSON_IMPORT` (`wardley:json:import`), `WARDLEY_JSON_EXPORT` (`wardley:json:export`), `WARDLEY_JSON_FORMAT`, `WARDLEY_JSON_EXTENSION`, `WARDLEY_JSON_MIME`, `importWardleyRendererJson` and `exportWardleyRendererJson`; both capabilities join `WARDLEY_INTERCHANGE`, so the editor lists an "Export Wardley as .json" view action and reads `.json` maps. The reader draws every Wardley element with the `WARDLEY_TOOLBOX` builders and their real parameters (kind, `wardley:nature` tag, colours, the name's offset); an evolution is the toolbar's change arrow to the target point, labelled with its type, never a second component; a description, a step, an evolution range, the title and the context are plain shapes and free texts. Nothing it cannot show is stored: no foreign id, no carried field, and the report names what was dropped. The writer needs no editor and reads back what is visible, minting ids from the names. Ten import remark keys `com.labre.wardley.import.json.remark.*` join the manifest.
