New optional `requireSource` on the data-source picker (`DataSourcePickerExtension({ ..., requireSource: true })`). The source decides, never the row count: a database with no source and no row, or whose source the host no longer resolves, draws an empty view ("No source connected") with a "Connect a source" button that reopens the creation popover (connecting the block, or re-pointing the hosted view); a database with no source but native rows shows them read-only; a connected database with no row is an ordinary table. Closing the popover still writes nothing. With a host picker, the mobile keyboard toolbar's "Table view" / "Kanban view" now run the slash entries' gesture, and "Create Table" is hidden when a source is required. New: `sourceRequirement`, `reconnectDatabaseView`, `canConvertToDatabase`, `canCreateDatabase`, `createDatabaseByGesture`, `HostedDataSourceBase.locked$`, `DatabaseCreationRequest.viewId` (`@labre/affine/blocks/database`), a `testId` on context-menu sub-menu entries, and three keys, `com.labre.database.source-required`, `.hint` and `.read-only`; the button reuses `com.labre.database.creation.title`, whose declaration moves to core (`DATABASE_CREATION_TITLE`, same key). Test ids for a host's end-to-end suite: `database-creation-new-source`, `database-creation-link-existing-entry`, `database-source-required`, `database-source-required-connect`, `database-source-required-read-only`. A host without a picker sees no change; a host with a picker but without the option sees only the mobile toolbar change.
