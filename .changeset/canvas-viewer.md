New entry `@labre/affine/canvas-viewer` (ADR 0050): `mountCanvasViewer(host, state, options)` mounts a read-only canvas from a stored Y.Doc state, with no editor around it, for a host's public page. It pans (drag, wheel, two fingers), zooms (ctrl+wheel, trackpad pinch, two fingers) and follows links: a page link goes to `onOpenDoc(docId)`, an external one to `onLinkClick(url)` after `isSafeLinkUrl`; `getBlob` feeds images. It returns `{ zoomIn, zoomOut, fit, dispose }` and fits once at mount. `focus: { kind: 'frame' | 'group', id }` shows one element the way a surface reference shows it in a page (its proportions, its bounds, a frame without its border); with it the view is frozen by default (`interactive`), lets the page scroll, and calls `onExpand` on a click or Enter so the host can open the same `focus` with `interactive: true`. It imports the whole view graph (3.65 MB gzipped, browser ESM): load it with a dynamic `import()`. The wheel and pinch maths of the edgeless root moved to `zoomAtPointer`, `panByWheel` and `pinchStep` (`@labre/affine-block-root`), shared by both; the editor's behaviour does not change. `docTitles` names the other pages for page references and linked doc cards. The viewer holds under a strict Content-Security-Policy (no `'unsafe-inline'` styles, no `'wasm-unsafe-eval'`): new `adoptShadowlessStyles()` in `@labre/std` moves light-DOM styles to adopted style sheets (the editor keeps `<style>` elements unless a host calls it), new `CodeBlockConfig.engine: 'oniguruma' | 'javascript'` (default `oniguruma`) highlights code without WebAssembly, and the paragraph block's in-template `<style>` moved to its static styles.
